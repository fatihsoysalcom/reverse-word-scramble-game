# Reverse Word Scramble Game

This Python script implements a simple word scrambling game where the goal is to guess the original word from its jumbled letters. It demonstrates how to programmatically shuffle letters while ensuring the scrambled word is different from the original, simulating a cognitive challenge.

## Language

`python`

## How to Run

1. Save the code as `reverse_word_scramble.py`.
2. Run from your terminal: `python reverse_word_scramble.py`
